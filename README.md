# ゴーストエージェント（β版）

**昨日の自分を、ちょっと超える。** 自分の自己ベストが「ゴースト」になって、一緒に走るアプリです。競う相手は、ほかの人ではなく昨日の自分。推し活SNS「ともはね」とつながります。

> 創業計画書（ゴーストエージェント／スポーツ支援）の最初の一歩です。アイデアノートの「家で試すとき（決定）」のとおり、まずは**ラップを計って、テレビに今日と昨日のタイムを出す**ところから。光のゲートやカメラは、まだ使いません。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3500
npm test
```

| 環境変数 | 中身 |
| --- | --- |
| `TOMOHANE_URL` | ともはねのアドレス（ふだんは `http://localhost:3000`） |
| `LINK_SECRET` | ともはね と同じ値にする合言葉。**本番では必ず設定する** |
| `GHOST_DATA` | 記録の置き場所（ふだんは `data/`。git に入らない） |
| `PORT` | ポート（ふだんは 3500） |

## 使い方

1. ともはねの町の地図で「👻🏃 グラウンド」を押す →「ともはねでログイン」
2. 種目（ラジコン・ランニング・ウォーキング・リハビリの歩行・そのほか）を選ぶ
3. 「スタート」→ 1周ごとに「1周！」ボタン（またはスペースキー）
4. パソコンをテレビに HDMI でつなぐと、大きな画面で見られる

## 画面

- **大きなタイマー**と、**ゴースト**（自己ベストの速さで進む）。「ゴーストのゴールまで あと〇秒」「ゴーストはゴールした（＋〇秒）」
- **自己ベスト・今日のベスト・昨日のベスト・昨日との差**
- 今日のラップの一覧（自己ベストは色つき）
- **やさしさの強さ**（燃える／ふつう／やさしい）で、キャラの言い方が変わる

## キャラ

| キャラ | 役目 |
| --- | --- |
| 👻 ゴースト（もう一人の自分） | 自己ベストの速さで一緒に走る。はじめての記録がゴーストになり、抜かれると「新しいゴーストは、きみだ」 |
| 🐰 ウサギ | 自己ベスト更新のお祝い |
| 🐕 シバ | 応援（やさしさの強さで言い方が変わる） |
| 🐱 ヤマネコ | 分析（6周目から3周ごと：後半がおそい／速い） |
| 🦉 フクロウ | **見守り**：長く続けすぎ（子ども20分・中高生30分・大人45分）、ラップが落ちてきた → 休けいをすすめる。**医療の判断はしない** |

## ともはねとのつながり

- 「ともはねでログイン」：ともはねが1分だけ・1回だけの通行証を出し、合言葉つきで確かめる（ともじゃんと同じしくみ。番号はアプリごとにちがう）
- ゴーストが受けとるのは、アプリ用の番号・表示名・年齢の区分だけ
- ともはねに返すのは、**自己ベストを更新した回数**と**続けた日数**だけ（ラップの記録そのものは送らない）。アカウント画面に出る
- 自己ベストを更新したら「**ともはねの広場で知らせる**」→ 広場の投稿欄に下書きが入る。**送るかどうかは本人が決める**（送る前のチェックも通る）

## 守ること

- 記録は**本人のもの**。ほかの人には見せない。「記録を全部消す」でいつでも消せる（ともはねの数も 0 にもどる）
- 1周の時間は1秒〜60分だけ受けつける（押しまちがいを数えない）
- ケガや体調の**医療の判断はしない**。休けいをすすめ、「痛みがあれば大人やお医者さんに」まで
- 公式戦の試合中に使うかどうかは、リーグのルールを確認してから。β版は練習用
